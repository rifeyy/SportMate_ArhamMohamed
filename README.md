# SportMate Mobile App

SportMate is an Android application for managing and organizing sports activities.

## Features
- User authentication (Register / Login)
- Create and join sports events
- GPS & Google Maps integration
- QR Code Scanner
- Voice Search
- AI Chat Assistant (Gemini AI)
- Firebase integration (user actions logging)

## Technologies
- Android (Java, XML)
- Node.js / Express.js
- MongoDB
- Firebase Firestore
- Retrofit API
- Gemini AI
